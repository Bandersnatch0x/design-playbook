# 事件流监控页 交互设计 Spec

Produced by **ux-spec**（design-playbook 管道 dogfood，2026-08-01）。

## L1 定位与意图

- 一句话定义：实时事件流监控页——运维/开发查看系统事件（部署、告警、审计）的持续滚动列表，按严重级别区分并可暂停细读。
- 目标用户：运维分析师、开发；无登录。
- 场景：事件流浏览（持续追加）、级别筛选、暂停/恢复滚动、事件详情聚焦。
- 非目标：不做事件来源配置/告警规则编辑、不做多用户、不做后端实时推送（demo 用前端模拟流）、不做移动端深度适配（桌面优先）。
- 行为边界：暂停滚动 = 点击即切换（无破坏性）；事件详情 = 点击行展开（无确认）；级别筛选 = 点击过滤即时生效；不引入外部依赖（自包含页面）。

## L2 信息架构

- 顶栏：标题「事件流」+ 暂停/恢复按钮 + 级别筛选（全部/关键/警告/信息）。
- 主区：事件列表（时间戳 + 级别徽章 + 来源 + 消息摘要），新事件自上端追加。
- 详情区：点击行展开的内联详情（完整消息 + 关联字段）。
- 状态区：计数徽章（事件总数 + 关键数）。

## L3 核心链路

- 进入页面 → 模拟流开始追加事件 → 列表滚动浏览。
- 点击行 → 内联展开详情 → 再次点击收起。
- 点击暂停 → 流停止追加 → 再点恢复。
- 选择级别筛选 → 列表过滤即时生效（计数联动）。
- 新事件追加 → 顶部插入 + 计数更新（暂停时不追加）。

## L4 组件功能细节

- 事件行（event-row）：时间/级别徽章/来源/摘要；关键级左侧警示条；可展开；键盘可达。
- 级别徽章（severity-badge）：status 角色——critical/warning/info 三态（色 + 文本双编码）。
- 暂停按钮（pause）：action 角色；两态（暂停/恢复）切换，文本 + aria-pressed。
- 筛选组（filter）：radio-group 语义；选中态可见。
- 计数徽章（counter）：status 角色。

## L5 边界条件

- **空态**：无事件时显示「暂无事件」+ 说明 + 刷新按钮；非空白。
- **加载态**：初始用骨架行占位。
- **错误态**：流源失败显示错误文案 + 重试。
- **权限态**：本页无权限要求；N/A 标注。
- 每态给出下一步。

## L6 验收标准

- **L6.1 首屏渲染（Given -> When -> Then）**：Given 打开页面 When 加载完成 Then 显示事件列表（含时间戳/级别徽章/来源/摘要，非空白），证据 = 首屏截图（capture seed: `ready-state screenshot`）。
- **L6.2 级别区分（Given -> When -> Then）**：Given 含多级别事件 When 检查列表 Then 关键级有警示条 + 徽章（色 + 文本），与 info 级可区分，证据 = 列表截图（capture seed: `severity screenshot`）。
- **L6.3 详情展开（Given -> When -> Then）**：Given 事件行 When 点击 Then 内联展开完整消息，再点收起，证据 = 交互 trace。
- **L6.4 暂停/恢复（Given -> When -> Then）**：Given 流在追加 When 点击暂停 Then 计数停增且按钮显示「恢复」，再点恢复继续，证据 = 交互 trace。
- **L6.5 级别筛选（Given -> When -> Then）**：Given 选择「关键」When 点击过滤 Then 仅关键事件可见且计数联动，证据 = 交互 trace。
- **L6.6 可访问性（Given -> When -> Then）**：Given a11y 树 When 检查 Then 每行/按钮/徽章有可访问名，暂停按钮有 pressed 态，证据 = a11y 树（capture seed: `a11y tree`）。
- **L6.7 空态（Given -> When -> Then）**：Given 无事件 When 渲染 Then 显示「暂无事件」文案非空白，证据 = 状态截图（capture seed: `empty-state screenshot`）。

每项声明证据类型（截图 / 交互 trace / a11y 树），runtime 状态命名 capture seed。
