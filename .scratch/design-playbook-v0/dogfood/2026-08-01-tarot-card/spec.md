# 塔罗牌浮雕显示页 交互设计 Spec

Produced by **ux-spec**（design-playbook v0.9 管道 dogfood，2026-08-01）。

## L1 定位与意图

- 一句话定义：以浮雕（embossed relief）视觉语言展示塔罗牌卡的陈列页——卡面线条凸起、边缘高光、光影层次，可翻牌揭示与单卡聚焦。
- 目标用户：塔罗爱好者 / 展示与收藏场景；无登录。
- 场景：卡片陈列浏览（牌阵视图）、单卡翻牌揭示、单卡放大聚焦。
- 非目标：不做占卜/抽牌解释逻辑、不做多用户/后端、不做卡片数据库管理、不做移动端深度适配（桌面优先）。
- 行为边界：翻牌揭示 = 点击即翻（无敏感信息，无需确认）；洗牌 = 点击按钮触发动画重排；单卡放大 = 点击正面卡聚焦；键盘可导航（Tab + Enter/Space）。

## L2 信息架构

- 顶栏：页面标题「塔罗牌浮雕陈列」+ 洗牌按钮 + 全部翻回按钮。
- 主区：牌阵陈列网格——每张牌以卡背（浮雕纹样）展示，翻牌后显示卡面（浮雕牌面）。
- 聚焦区：单卡放大视图——翻开的卡点击后居中放大，显示卡名、编号、牌意短语；Esc 或点击空白关闭。
- 状态区：计数徽章——已翻开 N / 总数 M；加载/空态文案。

## L3 核心链路

- 进入页面 → 卡背牌阵渲染（浮雕卡背）→ 浏览。
- 点击卡 → 翻牌动画 → 卡面浮雕揭示 → 计数 +1。
- 点击已翻开卡 → 聚焦放大（lightbox）→ 查看卡名/编号/牌意 → Esc/空白关闭。
- 点击洗牌 → 洗牌动画 → 牌序随机重排 → 全部翻回。
- 点击全部翻回 → 所有牌回到卡背，计数清零。

## L4 组件功能细节

- 卡组件（tarot-card）：卡背态 / 卡面态 / 聚焦态；浮雕效果 = 多层渐变高光 + 阴影 + 内浮雕线；`aria-label` 含卡名；键盘可聚焦。
- 洗牌按钮（shuffle）：点击触发；动画期间禁用（loading tier 2）；完成后恢复。
- 计数徽章（counter）：status 角色；翻开数实时更新。
- 聚焦层（lightbox）：覆盖层 + 放大卡 + 说明文字；Esc / 点击遮罩关闭；焦点陷阱。

## L5 边界条件

- **空态**：无卡数据时显示「牌库为空」+ 重载按钮；非空白。
- **加载态**：初始渲染用骨架占位（skeleton 卡形），非空白。
- **错误态**：数据加载失败显示错误文案 + 重试按钮。
- **权限态**：本页无权限要求（纯前端展示）；不适用，标注 N/A。
- 每态给出用户可做的下一步。

## L6 验收标准

- **L6.1 首屏渲染（Given -> When -> Then）**：Given 打开页面 When 页面加载完成 Then 显示完整卡背牌阵（非空白、每卡可辨认），证据 = 首屏 viewport 截图（capture seed: `ready-state screenshot`）。
- **L6.2 浮雕质感（Given -> When -> Then）**：Given 任一卡面渲染 When 检查卡面样式 Then 存在浮雕视觉层（高光渐变 + 阴影 + 内线），非平面纯色，证据 = 卡面截图（capture seed: `card-face screenshot`）。
- **L6.3 翻牌揭示（Given -> When -> Then）**：Given 卡背牌阵 When 点击任一卡 Then 翻牌动画后显示该卡卡面且计数 +1，证据 = 交互 trace。
- **L6.4 单卡聚焦（Given -> When -> Then）**：Given 已翻开的卡 When 点击它 Then 放大聚焦视图显示卡名/编号/牌意且 Esc 可关闭，证据 = 交互 trace。
- **L6.5 洗牌重排（Given -> When -> Then）**：Given 已展示的牌阵 When 点击洗牌按钮 Then 牌序随机变化并全部翻回卡背，证据 = 交互 trace + 前后对比截图。
- **L6.6 可访问性（Given -> When -> Then）**：Given a11y 树 When 检查 Then 每张卡有可访问名与角色、计数/按钮有可访问名、无空 alt，证据 = a11y tree 捕获（capture seed: `a11y tree`）。
- **L6.7 加载与空态（Given -> When -> Then）**：Given 模拟慢加载或无数据 When 页面渲染 Then 加载态显示骨架、空态显示「牌库为空」文案，均非空白，证据 = 状态截图（capture seed: `loading-state screenshot` + `empty-state screenshot`）。

每项验收均声明证据类型（截图 / 交互 trace / a11y 树），runtime 状态命名 capture seed。
