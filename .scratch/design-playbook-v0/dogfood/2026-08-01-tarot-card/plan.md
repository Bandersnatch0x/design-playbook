# plan — 塔罗牌浮雕显示页

## 1. 本次 run 范围

- L2 主区（牌阵网格）+ 聚焦区（lightbox）+ 顶栏（洗牌/翻回）+ 状态区（计数）。
- 桌面优先；非目标：占卜逻辑、后端、移动深度适配（见 spec L1）。

## 2. 用户描述 → spec 映射

| ask 描述 | spec 落点 | 说明 |
| --- | --- | --- |
| 塔罗牌显示页面 | L1 目标 / L2 主区牌阵 | 陈列展示核心 |
| 浮雕（embossed relief） | L2 卡组件 + L6.2 浮雕质感 | 视觉语言 = 高光/阴影/内线多层，非平面 |
| 交付页面 | 全部 L6 | 产物 = 自包含 HTML 页面（filled-ui.html） |
| （未明说）翻牌/洗牌/聚焦 | L3 链路 + L4 组件 | 保守假设：展示页需基本交互（翻牌揭示、洗牌、单卡聚焦），已入 L3/L4 |

未映射项 → 无；全部 ask 意图已覆盖。假设：78 张大阿卡纳+小阿卡纳全集过重，用代表性 12 张牌（大阿卡纳 0-11）作为牌阵数据，卡名/牌意占位文案。

## 3. ui-picker 输入包

- scene：detail/collection 陈列（卡片墙）
- density：marketing-loose 偏展示（浮雕质感需要呼吸空间），网格密度适中
- 约束：卡组件必须有浮雕视觉层（L6.2）；翻牌/聚焦/洗牌交互齐全（L6.3-6.5）；键盘可达（L6.6）；骨架与空态（L6.7）
- 排除：不做牌义占卜引擎、不做后端、不引入外部字体依赖（CJK 用系统栈）
- 参考 contract：无（本 run 无 reference-intake）
