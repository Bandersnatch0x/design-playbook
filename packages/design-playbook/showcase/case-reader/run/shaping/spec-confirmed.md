# 案例阅读器 — 规格草案，待范围确认

## L1 Positioning and intent

- User-visible goal: 在一个离线只读页面内按用户旅程查阅真实案例原文，区分历史证据与当前命令说明，不靠模拟业务操作解释插件价值。字段 l1.goal。
- Target user: 阅读项目案例的工程师、设计 / 产品协作者和评审者。字段 l1.target_user。
- Scene list: 团队分享后自助阅读；查明需求、设计与评审的来源；为当前项目找到接续和交付入口。假设 l1.scenes，需本轮明确确认。
- Non-goals: 不运行插件或真实后台任务；不改写原始记录；不新增后端、账号、遥测、网络依赖或第三方组件库；不把历史通过迁移给当前项目。字段 l1.non_goals。
- Behavior boundary: always 显示来源与边界并使用真实文本；ask first 新依赖、外部发布、扩大写入范围或改变验收标准；never 代用户确认、生成假证据或把案例当运行状态。假设 l1.boundaries，需本轮明确确认。

## L2 Information architecture

- 目录区展示旅程阶段及可读材料；正文区展示唯一当前文档，标题、案例归属和证据边界先于原文。
- 案例材料 A / B / C 分开，状态与交付命令归为使用说明；来源文件路径与 SHA-256 可核验。
- 文档集由仓库已有文件构建并内嵌，不在浏览器加载外部内容。过滤只影响目录，不静默更改当前原文。

### Page duties

| Page | Duty |
| --- | --- |
| reader | 以来源清晰的目录和原文帮助读者查阅一个材料；不执行其中命令。 |

## L3 Core flow

### Paths

| Path | Steps |
| --- | --- |
| P1 | reader 目录 → 选择材料 → 阅读来源、边界与原文 → 按旅程选择下一材料。 |
| P2 | reader 搜索 → 有结果 → 打开结果；无结果 → 清除搜索 → 返回目录。 |
| P3 | reader 深链接 → 正确原文 → 刷新 → 相同原文 → 后退 / 前进恢复；无效标识 → 明确错误 → 返回首篇。 |
| P4 | reader 窄屏或键盘进入 → 跳至目录 / 正文 → 选择材料 → 阅读完整正文。 |

## L4 Component behavior detail

- 原生链接选择材料并更新片段 URL；选择后焦点到正文标题，后退 / 前进同步文档。
- 搜索输入有明确标签，按材料标题、旅程与案例来源过滤；清除按钮恢复全部项目。搜索不会执行原文。
- 当前材料有 aria-current；边界和来源使用正文而非只依赖颜色或悬停提示。原文作为纯文本写入，HTML / 脚本内容不可执行。
- 阅读器无写操作或权限升级入口；没有可被误认成运行 / 验收按钮的装饰控件。

## L5 Edge conditions

- Empty: 搜索无匹配时显示无结果与清除入口，当前正文仍可读。
- Loading: 同步读取内嵌文本，无异步数据加载；不伪造加载动画。
- Error: 无效 URL 标识显示不存在提示，不默认显示错误材料；提供返回首篇的链接。
- Permission: 只读数据，没有修改案例的权限；禁用脚本时明确说明所需能力，提供目录文档入口。

### Five-state matrix

| Page | initial | loading | success | failure | empty |
| --- | --- | --- | --- | --- | --- |
| reader | 首篇材料与全目录 | n/a (内嵌同步数据，无网络请求) | 所选材料与真实原文 | 未知片段显示错误和恢复链接 | 无搜索结果显示清除入口且保留原文 |

## L6 Acceptance criteria

- Given 本仓案例及命令源文件，When 打开目录中每份材料，Then 页面原文与对应文件字节解码文本一致且显示正确的案例归属、源路径和 SHA-256；历史记录与命令说明不混淆。(path: P1)
  - Required evidence: 真实源文件对照自动检查；默认 / 所选材料截图与 a11y tree；所有材料逐项核验。
- Given 材料目录与当前正文，When 搜索匹配或不匹配词并清除，Then 目录准确过滤、无结果有恢复入口，正文内容不会被过滤隐式替换。(path: P2)
  - Required evidence: 搜索交互自动检查；无结果截图；清除后结果恢复断言。
- Given 任一合法或非法片段 URL，When 直达、刷新、前进后退或从错误恢复，Then 所选文档与 URL 一致，未知标识不冒充有效材料且能恢复。(path: P3)
  - Required evidence: 深链接 / 刷新 / 历史自动检查；错误状态截图和恢复交互。
- Given 1440、768、390 像素视口或仅用键盘，When 选择并阅读材料，Then 目录和正文可达、焦点明确、没有整页横向溢出，长原文可换行；禁用脚本时说明限制而不假装运行正常。(path: P4)
  - Required evidence: 三视口截图与几何断言；Tab / Enter 和焦点检查；无脚本状态截图或 a11y tree。
- Given 断网且原文含 HTML 标记，When 在阅读器和静态交付副本中阅读，Then 内嵌材料可访问、不发起外部请求、不执行原文，不需要原项目服务器。(path: P1)
  - Required evidence: 断网、原文 textContent 与无脚本注入检查；真实交付副本复跑。
