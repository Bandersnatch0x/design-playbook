# v0.24.0

Minor release prepared 2026-09-19. It adds an adapter lifecycle check to the
packaged doctor: generated `init` artifacts in a target repository are
checked for drift against the installed package's templates, with a
copy-pasteable refresh path.

## Adapter lifecycle check

`npx design-playbook init` artifacts carry a versioned generated-by marker.
The packaged doctor now reports, per file, whether re-running init with the
installed package would change it:

- **Attribution boundary.** Only marker-bearing files are judged. Files
  without the marker (user-authored content, marker-less JSON merge targets)
  are never attributed or touched; a repository with no markers anywhere
  gets a single not-initialized line instead of a full scan.
- **Mechanical drift semantics.** Expected content is re-rendered through
  the same renderer path as init (a new read-only `render_entries` seam; the
  generator CLI and dry-run output are byte-preserved) and compared after
  marker-version and CRLF normalization. A stale marker with identical
  content is clean — version lag alone never triggers a refresh warning.
- **Shared targets.** AGENTS.md is rendered by one dedicated agent and by
  every floor agent; a file is clean when it matches any current candidate
  render, so one agent's artifact is never another agent's false drift.
- **Orphans.** Files carrying our marker outside the current manifest paths
  in namespaced output directories are reported with a
  delete-then-re-init repair.
- **Fail-open.** Unreadable renderer inputs (malformed merge JSON,
  undecodable marker files) degrade to a `render_error` finding; the doctor
  never crashes on a hostile repository and the remaining agents still
  classify.
- **Report-only.** The check is read-only (pinned by a monkeypatch test),
  non-required in the doctor verdict, and never gates a release or install.

## Verification

Real-corpus closed loop: init artifacts generated by the v0.21.1 templates
for five representative agents produced 33 genuine drifts; the current
doctor detected all 33, a current-version re-init cleared every one, and the
re-checked corpora reported clean. A fresh-init matrix over all 28
non-native agents reports zero false positives. Two-axis review (Standards
and Spec) passed with every finding resolved, including a fail-open fix for
hostile repository states. Full local suite green on both the packaged and
monorepo groups; release gates (validate, seam, adapter floor) green.
