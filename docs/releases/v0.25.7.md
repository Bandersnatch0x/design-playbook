# v0.25.7

Release prepared 2026-11-04. An architecture-deepening release: concepts that
had been implemented twice now have one owner, and the work-request counter
gap is closed under the ADR-0045 amendment. No command, skill, or MCP server
is added or removed.

## One owner per concept (workbench)

- **Publication.** One `PublicationService` owns revision creation, closure
  checks, the ledger row, and the response assembly. The six publish entry
  points no longer splice validation output onto a recorded result, so a
  retry returns exactly what the first call recorded.
- **Canvas legality and undo patches.** Instance legality is decided by the
  one document validator; undo/redo patches are derived from the command's
  effect instead of per-branch bookkeeping, so a new command cannot forget a
  touched node.
- **Document writes.** Component, page, and token drafts share one write
  sequence and one canonical text shape; token validation runs at the same
  gate moment as the other documents.
- **Stored rows.** `rows.py` owns how stored JSON columns decode and
  `owned_asset` owns the identity guard; about sixty hand-rolled decodes are
  gone. A corrupt column falls back to the caller's shape on read paths,
  while the lifecycle corruption scan keeps its strict decode.

## Repair Packet in the snapshot (ADR-0050, T-138)

`repairPacket` is now a required Run Snapshot v1 section derived by the
snapshot builder. The console renders it and the JavaScript re-derivation is
gone, together with the node-executed mirror test; the console keeps only the
copy text and localization. `scripts/frontend_review.py` still reads the same
Python projection.

## Work-request counters (T-127, ADR-0045 amendment)

Work-request writes compare the request counter through the one mutation
gate; the workbench client refreshes the row before acting, so an interleaved
agent write is a conflict rather than a lost update. Proposals have no
counter column and use the payload digest as their concurrency unit.

## Run console, preview, adapters, and gates

- The run console's routes and action names are generated from one Python
  owner; the locator grammar is owned by the registry alone.
- A `report_ref` resolves through one rule, and the preview shell now says
  why acceptance criteria are unavailable instead of showing an empty list.
- Each distribution has one loopback listener module; the preview review
  server gained the Windows half-close/drain teardown.
- Cordis commands are derived from `commands/*.md`, Python frontmatter
  parsing is shared, and `test_commands.js` runs in CI.
- Adapter tier and renderer availability are one matrix fact: a Tier-1/2 row
  cannot be built without its renderer.
- A generated-artifact register is checked by `validate.py`; the workbench's
  unread `dpbui-core.js` copy and the unread `capture_snapshot.py` whitelist
  are deleted.
