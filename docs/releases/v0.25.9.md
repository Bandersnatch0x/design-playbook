# v0.25.9

Release prepared 2026-11-11. A patch release over v0.25.8 with no new command,
skill, or MCP server. It fixes a regression introduced by v0.25.8's complete
acceptance default, and one spelling inconsistency that made otherwise valid
ledgers unreadable by later gates.

## The evidence gate is conditional again

- `validate_run.py` no longer treats "no evidence authority given" as "every
  reference is unavailable". With `--legacy` (or a selective `--require-*`
  set) and no `--run-root` / `--evidence-dir`, G6 keeps its historical
  conditional scope: declared references are not read, and nothing is reported
  as a missing artifact.
- Complete acceptance is unchanged. A bare or `--strict` run still fails
  closed through the required-evidence gate, so the loosened scope cannot be
  mistaken for a passing audit. When an authority *is* given, a reference
  whose bytes are absent still fails with `G6.artifact_missing`.
- G4 repair proof follows the same split: without an authority it keeps the
  structural reading (declared pairs are checked for shape and
  `reference_prefix` only) instead of binding to artifacts it cannot read.

## Criterion tokens are canonicalized once

- `criterion_token()` in `mcp/evidence/ledger_syntax.py` is now the single
  owner of the leading criterion token. `L6.01`, `l6.1`, and `L6.1` all
  normalize to `L6.1`, the spelling G2 already accepted case-insensitively.
- G4 repair-evidence retests, G6 ledger projection, point-back projection, and
  owner publication all use it. Previously a lowercase or zero-padded
  criterion passed the ledger syntax gate and then failed downstream with
  "0 current ledger rows" or a `KeyError`, which read as a missing row rather
  than a spelling difference.

## Manifest references are prefixed once

- `run_facts` adds the `evidence/` prefix only when the recorded reference does
  not already carry it, so a manifest written with the canonical token is no
  longer rewritten to `evidence/evidence/<leaf>`.

## Diagnostics

- The `artifact_facts_unavailable` message now names both ways to supply the
  missing authority (`--run-root`, or `--evidence-dir`) and the option to
  recapture the snapshot, instead of implying the run itself is broken.
- The package README states that G6 needs an explicit evidence authority; the
  v0.25.8 notes gain the `--legacy` + `--strict` usage-error rule.

## Tests

- Seam coverage for the three authority shapes (none / `--evidence-dir` /
  `--run-root`) at the `validate_run` boundary, so the conditional scope
  cannot silently regress again.
- Case-variant and zero-padded criterion tokens across the ledger syntax, G4,
  point-back, and publication paths.
- Manifest reference prefixing: bare leaf, already-prefixed token, malformed
  line.
