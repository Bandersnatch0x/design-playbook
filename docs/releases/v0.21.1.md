# v0.21.1

Patch release prepared 2026-08-28. 34 commits since v0.21.0: the v10
spec-matrix review workbench, a findings-bound motion/state polish pass,
the multi-platform adapter generator, an English pass over the shipped
skills, and repo hygiene (nightly CI removal, stale-doc cleanup).

## Preview workbench (v10, ADR-0041)

- **Spec Matrix pane** — the run's L6 acceptance criteria render beside
  the prototype, parsed by the `g1_spec` owner parser from the
  `report_ref` sibling `spec.md`. Checkboxes are the human reviewer's
  verification record and persist additively as `criteria_review` in
  `confirm-round-N.json`; no machine gate states are shown at G5 time,
  and the server rebuilds titles from the authoritative criteria so a
  tampered payload cannot rename them.
- **Criteria counter + sign-off** — header shows reviewer progress
  (`准则 N/M`), the primary CTA reads 确认签署决策 / "Confirm & sign
  decision" (the label union keeps historical spellings valid).
- **Box + Ruler tools** — drag-a-rectangle annotations join the anchors
  payload additively; the ruler is a transient hover-size / two-click
  distance probe (nothing persisted), bridged into sandboxed prototype
  iframes.
- **Theme toggle** — manual light/dark switch with SVG icons, persisted
  per machine, honoring the explicit-attr > stored > system precedence.

## Polish (findings-bound F1–F11)

Unified spring motion tokens with tactile press feedback across every
control, pin-drop entrances and an active-pin pulse (parent layer and
iframe bridge), `prefers-reduced-motion` coverage scoped to workbench
chrome only — the prototype under review is never altered — a
criteria-toggle open state, checked-card wash, a previously unrendered
drawer empty state, and reassurance copy for empty states (zh + en).

## Multi-platform adapter (ADR-0042)

- `npx design-playbook init <agent>` (npm bin shim delegating to
  `scripts/generate_adapter.py`) renders per-platform artifacts from the
  canonical skills/commands/MCP sources across a 29-agent, three-tier
  capability matrix: Tier 1 full fidelity (Claude Code, Codex), Tier 2
  skills + MCP (Cursor, Gemini CLI, OpenCode, Windsurf, GitHub Copilot),
  Tier 3 AGENTS.md floor (22 agents).
- Consumer safety: merge-safe JSON emission fails loudly on malformed
  existing config; shared markdown targets use design-playbook marker
  blocks that preserve user content and re-render idempotently; Windsurf
  MCP (global-only) ships as a guide, never a write to user config.
- `.codex-plugin/` and `codex/AGENTS.md` are now generated committed
  snapshots guarded by a validate.py/doctor.py drift gate.
- READMEs gain a cross-platform install section with the honest tier
  table (zh + en).
