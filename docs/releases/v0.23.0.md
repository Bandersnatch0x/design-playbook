# v0.23.0

Minor release prepared 2026-09-18. It activates cross-run learning over the
frozen dogfood corpus, hardens operator evidence collection (probe binding,
finding identity, storage_state boundaries), and adds static preflight for
the capture contract.

## Cross-run learning is live

`aggregate_runs` keys runs by their `.scratch`-relative path, so same-basename
runs (two PR review trees) no longer silently overwrite each other in the
rollup. Pre-v0.20 legacy severities are folded mechanically on the
derivation side with a per-candidate folded count; the G2 grammar surface
still rejects those spellings on new findings. `candidate_view` reports
`context_coverage` and the aggregate markdown surfaces it.

The first two governance events are recorded in the repo-root
`rules-governance.jsonl`: a candidate opened by the agent (GOV-2026-09-15-001)
and its user adjudication (GOV-2026-09-15-002) — the `none blocking` signal
was ruled a historical empty-findings placeholder, not a defect signal,
setting the precedent that placeholder text is not a finding. Adjudication
stays user-only.

## Operator evidence hardening

The evidence capture contract gains an operator-facing slice (T-018–T-022):

- **Probe binding.** A screenshot capture writes a `page-probe/v1` sidecar
  (`<stem>.probe.json`) next to the artifact. The manifest carries the
  sidecar path, and G6 binds the primary leaf to its criterion only through
  that path — echo-only claims no longer satisfy proof.
- **Finding identity.** Additive `id` / `status` fields on findings with a
  shared id-or-issue closure and unique current-close cardinality; the
  projector prefers explicit IDs over the source+issue fallback.
- **storage_state boundary.** Run-root-relative path-shape preflight plus
  fail-closed JSON loading with strict session parsing; secrets never enter
  the payload (the capture snapshot keeps only the trimmed relative path).
- **Shared action dialect.** `action_params` / `path_syntax` are shared pure
  modules referenced by both static preflight and runtime, so verb
  canonicalization and path rules cannot drift between the two surfaces.
- **Static collision detection.** Preflight reports same-stem sidecar
  collisions (`sidecar_collision`) and lexical artifact collisions before any
  browser starts; the single write-target resolver keeps main artifact and
  sidecar fail-closed on unsupported paths.
