# v0.20.1 - Review follow-ups and release hardening

Released 2026-08-16.

Patch: ships review and live-test follow-ups landed after v0.20.0, plus
race-condition and fail-closed boundary fixes found during final release review.

## Pipeline and product fixes

- Clarifies text-only model guidance and removes four live-test pipeline
  frictions across decision entries, escalation signals, run status, and the
  public skill surfaces (#45).
- Makes dual-track review folding fail closed, fences Fill declarations, and
  backfills the vNext specification and queue-monitor showcase (#46).
- Fixes shaping queue item granularity, adds bounded npm provenance retries to
  the release workflow, and backfills showcase and point-back fixtures (#47).

## Queue monitor reliability

- Prevents delayed skeleton rendering from restoring dialog state after cancel.
- Locks Esc, backdrop, cancel, and retry-scope changes after confirmation so an
  accepted retry cannot be visually cancelled while still completing.
- Owns both dialog timers explicitly and clears them on open, close, and
  completion; resets loading/disabled controls between dialog sessions.
- Adds real-Chromium regressions for skeleton cancel, backdrop cancel, confirmed
  retry locking, single execution, selection cleanup, and queue counters.

## Contract hardening

- Rejects unsupported run-profile markers (`v2`, `v99`, and future unknown
  versions); unversioned and explicit `v1` markers retain current behavior.
- Makes evidence `wait_for_state` honor both optional selector and required
  `data-state` instead of ignoring state when a selector is present.
- Derives learning candidates only from valid defect severities `S3|S2|S1`;
  `S0`, blank, legacy, and unknown values are excluded fail closed while raw
  occurrence projection stays unchanged.
- Removes unused shaping-log `_pending_ids` code.

## Verification

- Targeted regressions: run-profile, learning candidates, evidence runtime, and
  queue-monitor Chromium suites pass.
- Full local matrix: `scripts/validate.py`, doctor, document links, and pytest
  pass (`629 passed`, `164 subtests passed`).
