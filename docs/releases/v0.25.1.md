# v0.25.1

**Withdrawn.** This version was published on 2026-09-26 and withdrawn the same
day: three links were broken on the published package surface, as described
under "Published-surface link repair" in [v0.25.2](v0.25.2.md). The GitHub
Release and tag were removed, and `dsh-design-playbook@0.25.1` was unpublished.

`design-playbook@0.25.1` remains on the npm registry, deprecated in favour of
[v0.25.2](v0.25.2.md). The registry refuses to unpublish a package that other
packages depend on, and that criterion is package-level: every published
`dsh-design-playbook` version declares `design-playbook` as a dependency, so no
`design-playbook` version can be unpublished while the bundle exists.

Content is otherwise identical to [v0.25.2](v0.25.2.md), which is the
supported build for this change set. Do not use this version.
