# v0.7.0 - preview decision transaction + advisory craft detectors + npm/pi surface

**Tag:** v0.7.0 · **Previous:** v0.6.0 · **Date:** 2026-07-27

## Summary

Minor bump for two subsystems that landed on `main` since v0.6.0 plus a third
distribution surface. The Preview G5 gate gains a durable, repairable decision
transaction (ADR-0013); craft-guard gains an advisory detector protocol
(ADR-0014); and the package now publishes to npm so it appears in the
[pi.dev package gallery](https://pi.dev/packages). Skills/commands content is
otherwise unchanged from v0.6.0.

## Changes

### feat(preview): durable decision transaction (ADR-0013)

- New `packages/design-playbook/mcp/preview/transaction.py` serializes preview
  decisions and structured errors, persists repairable state, and closes the
  durable decision gate so a confirmed + floor-passed decision survives across
  repair rounds instead of living only in the confirm record.
- `mcp/preview/server.py` slimmed onto the transaction seam; shared stdio
  dispatch moved into `mcp/_transport.serve_stdio` (evidence + preview both
  consume it). Dead `_now_iso` dropped from the evidence server.
- Seam/stdin coverage: `mcp/preview/test_transaction.py` (new),
  `test_server_stdio.py`, `mcp/test_transport.py`.

### feat(craft): advisory craft detector protocol (ADR-0014)

- craft-guard establishes a detector protocol with an evaluation loop over
  composition, context, and baseline detectors
  (`skills/craft-guard/references/detectors.md`).
- Detectors are **advisory** — they surface craft/anti-slop signals without
  becoming a hard gate; ui-evaluator rubric wording aligned.

### feat(dist): npm / pi publish surface

- New `packages/design-playbook/package.json` with the `pi-package` keyword and
  a `pi` manifest (`skills` → `./skills`, `prompts` → `./commands`), so
  `pi install npm:design-playbook` works and the gallery indexes the package.
- `package.json` version becomes the 5th manifest site policed by
  `scripts/release.py` and `scripts/validate.py` (7 version literals total incl.
  both README badges).
- README gains a pi install section (no plugin namespace: `/skill:<name>`,
  bare `/<command>`; MCP is opt-in via `pi-mcp-adapter` + bundled servers).

### refactor / ci

- `refactor(validate)`: centralize skill prose phrases (bool-guarded).
- `ci`: graduate the frontend floor browser gate.

## Test verification (local)

- `tests/` + `packages/design-playbook/tests/`: 54 passed.
- `tests/test_validate.py` + `test_release.py` + `test_doctor.py`: 19 passed.
- `scripts/validate.py`: VALIDATION PASSED (incl. npm/pi manifest gate).
- `scripts/release.py --checks version`: 5 manifest sites + both badges match.

## Known limitations

- pi has no built-in MCP; `preview*` / `observe*` skip by default under pi
  (ADR-0009 absent→skip). Enabling both gates needs `pi-mcp-adapter` plus a
  project `.mcp.json` registering the bundled servers.
- Craft detectors are advisory only — no gate signature, by ADR-0014.
