# v0.22.1

Patch release prepared 2026-09-08. It completes the owner-produced
Recirculate continuation facts in the read-only Snapshot / Repair Packet chain
and aligns the current release, product, trial, and version surfaces.

## Recirculate Repair Packet

The Recirculate next-action owner now emits three additional facts:

- the invalidated-evidence criterion set read from the owner-written
  `point-back.md` `invalidated:` block;
- the explicit `ui-evaluator` resume stage;
- the minimum recapture requirement.

`snapshot_builder.py` carries those facts into `nextActions.primary`, the
v1 schema/consumer contract requires them on the known Recirculate action, and
`repair_packet.py` plus the browser renderer project them without executing
anything. Missing or malformed invalidation facts remain explicit gaps; the
Console never infers them from progress, command prose, or a latest observed
stage. Artifact filenames and other point-back details stay out of the
path-free Snapshot boundary.

## Trial and distribution boundary

Run Console remains shipped as a **local, experimental, trial-gated**
capability. `G-RO-TRIAL-PASS` is **NOT SATISFIED**: the earlier participant
miss is preserved, participant collection remains deferred, and the
deterministic rehearsal is not participant evidence. This release record does
not publish packages, create tags, merge branches, or authorize a stable public
claim.

## Version and readiness surfaces

`design-playbook` and `dsh-design-playbook` are versioned at `0.22.1`, the DSH
bundle depends on `design-playbook ^0.22.1`, plugin/marketplace metadata and
README badges are aligned, and the Codex adapter snapshot is regenerated.
Capability receipts now expose the read-time inputs used for the projection
(package inventory, Console test presence, and the trial record) without
upgrading incomplete validation facts. PRODUCT.md names the Run operator as the
primary user and Semantic approver as the secondary user, and the current
adapter README count reflects the 22 Tier-3 agents.

## Verification

Focused status-projection, Snapshot builder, consumer-contract, and parity
tests cover the Recirculate path and its fail-closed gaps. Browser-based
Repair Packet checks require Playwright/Chromium and are executed by the full
CI matrix when available.
