# v0.25.6

Release prepared 2026-10-26. A maintenance release: it finishes the Stage P
consolidation inside the preview editor and upgrades the browser test bench.
No command, skill, or MCP server is added or removed.

## Preview visual editor

- **One pure layer.** The capture math (`cssPath`, `drawPathD`, the draw
  badge) and the theme/locale resolution now live in the shared UI core and
  are consumed by the shell, the bridge, and the React editor instead of
  being copied per surface. Node-style inspection behaviour is unchanged; the
  workbench's synced copy follows the same lock.
- **Generated wire contract.** The visual-edit contract is rendered from the
  server module into a generated JavaScript file, and a drift gate fails when
  a consumer reintroduces a hand-copied literal. The wire format itself is
  unchanged.

## Browser test bench

- Playwright is pinned at 1.63.0 (Chromium 153). The WebMCP surface
  assertion now branches by browser generation instead of pinning one
  generation's shape.
- CI gains a macOS leg that runs the same preview browser matrix with the
  locale chain pinned. Failed cases are retried once and the first-attempt
  failures are listed, so a genuine red stays visible; `pipefail` keeps a
  pytest usage error from hiding behind `tee`.
- Typing and history-shortcut tests now use the platform's own select-all and
  undo modifiers, and the history fixture waits for the editor round to
  settle before pressing a key. Assertions are unchanged.

## Also in this release

- Both READMEs are restructured around the product's positioning claims.
- Canvas drag/reload test failures report their state instead of only
  failing.
- Release recovery routes through one checklist table, guarded by a test.
