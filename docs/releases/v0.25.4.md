# v0.25.4

Patch release prepared 2026-09-30. It closes a **false-green hole in the
stdio pipe-encoding net** and wires the shared UTF-8 seam into every entry
point the net had been skipping. It also repairs the live-dogfood preflight
import and records the headless way to read the loaded plugin inventory.

The published surface is unchanged in shape: **9 skills / 8 commands**, the
same two bundled MCP servers, and no new gate or rule-registry entry
(ADR-0015 stable main — a patch release cannot move the version-line
inventory). `COMMAND_INVENTORY` keeps its `(0, 25)` row.

## Pipe-encoding coverage

Every shipped entry point must emit UTF-8 on a pipe whatever the host code
page says (T-105). Two nets guard that: a static check that each `__main__`
block wires the seam, and a dynamic sweep that runs each entry point under
cp1252 / shift_jis / gbk and asserts the bytes really are UTF-8.

The static net's `__main__` pattern required the line to end at the colon, so
any entry point written as `if __name__ == "__main__":  # comment` was skipped
entirely. Seven such entry points never called the seam and were invisible to
the check:

- `packages/design-playbook/scripts/project_target.py` and
  `scripts/publish_owner_projection.py` now call the shared
  `configure_piped_utf8()`.
- The zero-dependency workbench (`packages/design-playbook-workbench/`,
  `dependencies = []`, `tools/` unshipped, `__main__` reached only through its
  console script) cannot import that seam, so it carries the same rule inline
  and is registered in `INLINE_ONLY`; `perf_harness.py`'s stdout-only inline
  guard is widened to cover stderr as well.

The dynamic sweep also pins its long-running entry points (a wheel build, a
scale seed, a benchmark, the live install flow, the release gate chain) to a
usage path, so a bare run can no longer turn a code-page crash into a
minutes-long subprocess timeout.

## Live-dogfood preflight import

`scripts/vnext_live_dogfood.py` now takes `parse_capture_contract` from
`capture_contract` rather than `server`, so the preflight no longer trips on
an import that moved when the capture contract was factored out.

## Headless plugin inventory (docs)

`docs/agents/release-checklist.md` (gate 1) and `scripts/doctor.py` record the
headless way to read the loaded plugin inventory: `claude --plugin-dir ...
-p ok --output-format stream-json --verbose` emits an `init` record carrying
the loaded version and every `design-playbook:`-namespaced name
(15 = 8 commands ∪ 9 skills). Only the interactive `/help` rendering and
`/reload-plugins` stay human.
